# 安全边界与未验证项

本说明依据候选实现整理；测试结果以本次实际执行报告为准，列出控制措施不等同于生产安全认证。
当前仅准备本地源码候选，未生产部署。

## 身份、所有权与前端

用户由本地 CLI 显式创建，没有默认账号、匿名注册或全局关闭认证的开关。
密码使用 Argon2id，CLI 读取 getpass；登录失败统一响应并有本机来源限流。
服务随机生成 Opaque Bearer Session，仅返回一次，数据库保存摘要并检查有效期、撤销状态和用户 active 状态。
前端认证材料仅存页面内存，不写入 URL、localStorage 或浏览器持久账户状态。

业务 repository 使用当前 Principal 的所有权谓词；他人资源返回 404。
Agent 同时检查身份、运行 owner 和 workflow capability，UUID / trace ID 不构成授权。
运行时及任务写入前再次校验关键权限。旧 owner=NULL 资源保持隔离，不自动认领。
管理员、数据库管理员、本地 OS 和私密配置属于受信边界。

## LLM 重定向防护

`providers/openai_compatible.py` 默认创建私有 opener 和拒绝重定向处理器，
不修改全局 urllib opener。所有 HTTP 3xx 都分类为 RedirectError，包括同源、跨主机、
跨端口、循环和 HTTPS→HTTP；不会发出下一跳来转发认证头或正文。
`LLM_ALLOW_REMOTE=true` 只作用于最初配置的端点，不放开跳转。

异常不回显上游 URL、Location、认证头、响应正文或不可信异常链；API 使用
`502 / provider_redirect_blocked`。配置 URL 本身也拒绝嵌入凭据。
回归输入必须采用合成凭据和本地服务。

该实现不能替代操作系统出站隔离：初始端点、显式代理、受信测试 opener 和进程内代码仍可影响通信。
HTTPS 降级策略可以用合成 HTTPS handler 验证；这样的测试不构成实际 TLS 握手、证书或公网部署验收。

## 文本与审批

上传接受受限扩展名/MIME、严格 UTF-8、控制字符及实际字节大小检查；文件名仅保留 basename。
模型输出按 schema 校验，引用回查数据库和当前文档版本。
文档内容作为不可信证据，不能授予工具执行或人工审批权限；前端以普通文本呈现。
模型仍可能生成无依据推论或错误任务，必须人工审查。

批准绑定草案版本、摘要和证据；编辑后重审。正式任务只在批准后的事务中写入，
执行回执和唯一约束提供业务幂等。Checkpoint 与业务事务分开提交，不能当作一次性模型调用保证。

## 运行与配置限制

候选 Compose 使用独立命名资源与回环端口，API 不直接发布宿主端口。
核心 Docker/CI 排除 AI group，构建允许列表排除秘密、模型、数据库与浏览器状态。
CI 不上传日志原件、浏览器 Trace、凭据、数据库备份或模型缓存为 Artifact。

公开示例密码需要自行替换，当前配置类没有专门拒绝占位密码。
新 PostgreSQL 默认引导账号仍未拆分为最小权限运行/迁移角色。
尚无生产 TLS/MFA/SSO、完整网络沙箱、分布式限流、高可用或独立渗透审计。
使用 `production` 环境字符串不会自动补齐这些能力。

源码公开候选不启动服务，也不批准公网部署。依赖/模型许可未决项见 [许可证审查](license-review.md)。
